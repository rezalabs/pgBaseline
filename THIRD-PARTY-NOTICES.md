## PGTune

This project was inspired by PGTune (<https://github.com/le0pard/pgtune>, <https://pgtune.leopard.in.ua>). It reuses material from that project:

- the overall shape of the generated configuration and the order of its settings;
- the selection of settings and thresholds for each database type, including the workload-specific WAL sizes, parallel worker caps, and maintenance memory caps;
- several explanatory sentences, the `ALTER SYSTEM` explanation, the wording of the generated warnings, and the database type, storage, and size labels;
- the idea of a warning grouped by startup risk, memory risk, and note.

The implementation in this repository is a separate Svelte application. Its memory ledger, per-setting evidence and source citations, version support and end-of-life handling, form layout, and visual design are this project's own, and several rules differ deliberately; the Method page lists them.
